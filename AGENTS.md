# Install and open Creator Source Graph in the current AI host

When the user gives this repository URL to Codex or Claude Code and asks to install and open it, complete that workflow in the current subscribed host session. Do not ask the user to copy a task into another AI window or start a separate provider/API session for initial installation.

1. Read the public README and obtain the app in a persistent local folder. Use the release package matching this machine when Node is not available; bundled packages include `runtime/node` (`runtime/node.exe` on Windows). If using a source checkout with Node 20 or newer already available, `node` is sufficient. Preserve an existing installation and local account data. Verify release downloads against their `SHA256SUMS`; do not execute unrelated downloads or install a provider SDK.
2. Use the runtime from that app folder and run one setup command for the host currently doing this work:

   ```sh
   ./runtime/node cli.mjs setup --host codex
   ./runtime/node cli.mjs setup --host claude
   ```

   Choose one command. For source installations, replace `./runtime/node` with `node`; on Windows use `runtime\node.exe`. If the user also supplied a product/repository target to research, append that target URL. The repository URL used to install this app is not automatically a research target. Quote paths and URLs with the host shell's appropriate quoting; do not interpolate webpage text into commands. Run from the app folder, or use absolute runtime/CLI paths.
3. Setup uses the app's bundled skill without permanent host installation by default, launches/reuses the local app and opens its graph or Agentlas sign-in page. `--skip-skills` makes that choice explicit. Install to a personal folder only when requested, with `--skill-scope user`, or use `--skills-dir <parent>` for a chosen single-host location. An identical generated skill is reused without rewriting it. Preserve different/modified skills and obtain explicit replacement authorization before `--force`; do not use it with app/skip mode.
4. Read the receipt's `hostAction.skillFiles` immediately, so this same host session can continue without a restart or a second invocation. Its `bridge.commandPrefix` supplies the exact Node executable and app CLI path; append bridge commands as separate arguments. Use generated helpers only for an explicitly installed personal/custom skill. Do not infer that installation itself performs research, and never execute an unconfigured bundled helper or silently write to global skill folders.
5. If setup returns `loginRequired`, tell the user to sign in on the opened Agentlas page and preserve any `intendedProductUrl`. Use the receipt bridge's `login status` without reopening login. Pause web research until `authenticated: true`. Never ask for passwords, inspect browser cookies, copy tokens or bypass login. When authenticated, resume the same target; preserve the exact run ID if setup already created one.
6. If a target is present, follow the receipt skill now with this host's own search/browser tools on Instagram, YouTube, X and Threads. Preserve the opened target's language, market and concrete subject across 6–10 grounded keyword angles. Start with target-linked public accounts/posts/videos, marking operator-owned discovery seeds separately from source citations. Do not replace a Korean qualification niche with generic English study advice to fill quotas. Observe available views and trace actual citations or evidence-supported source candidates; blocked originals may leave zero source paths. Derive up to six subject-matched channel suggestions. For `create`, require opened channel, public feed/index, current rules and the rules page's observed submission hyperlink. For `investigate`, an opened relevant publication/community page can support `channel-candidate` while unknown submission/feed/rules routes stay null; declared routes still require opened evidence and observed hrefs. Consider Korean blogs, suitable cafe boards and study communities when the subject supports them, without defaulting to Show HN or developer launch channels. A public chat invitation is not a writing route or publicly indexed feed; `chat` stays investigate. Ordinary homepages, frameworks and papers remain references with placement:null. Never turn these suggestions into source edges or promise creator use/visibility. Import into the exact run and verify its graph and suggestions. Do not publish, join or execute suggestions. Without a target, leave the app open and ask for one; do not invent a default or mark a sample as completed research.

The initial workflow continues in the current AI chat without permanent skill installation. After Agentlas sign-in, the browser opens a centered URL form. Submit starts research and analysis; Back accepts another URL and View latest reopens retained results. Reanalyze also launches a new local subscribed CLI job, separate from the installing chat. Auto selects an available subscription route. Claude supports browser subscription sign-in or an existing setup-token environment inherited when this app starts; token configuration is not proof of remote token validity, and actual authentication failures require renewal. Do not read credential files, copy/store tokens, or use API-key providers. Missing/signed-out hosts show an actionable error before replacing the prior result.

Browser research jobs must actively trace explicit links, then investigate an evidence-supported inferred-candidate fallback when those paths are missing or incomplete. Open both endpoints and every supporting evidence page. Require distinctive content evidence and chronological context; search-only endpoints, snippets and generic similarity are insufficient. Submit only separately labelled low/medium-confidence candidates under the current import schema. If no candidate meets that standard, explain the missing evidence and submit none. Do not fabricate provenance or enforce a candidate-count target.

Browser jobs show progress and automatically import validated complete/partial results. Stop, sign-out and app shutdown abort the job; superseded or account-switched results must not import. Reanalysis creates a fresh run while preserving existing source records and run metadata, without offering historical graph restoration. Manual skill invocation and CLI run/import remain available. `/api/analyze` creates a ready run only; `/api/research` launches the installed host job.

The AI host’s subscription and tool limits apply. Agentlas login gates the local workspace and is separate from host subscription authentication. If the current host has no local shell access or cannot reach this machine’s loopback app, state that specific limitation without changing global account settings. Never inspect credential files or copy tokens to bypass missing host authentication.
